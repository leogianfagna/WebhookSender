<div align="center">
  <h1>🖥️ WebhookSender</h1>
  <p>Envio de webhooks para o Discord com formatos prontos.</p>

  [![Tecnologias](https://skillicons.dev/icons?i=bootstrap,js,discord)](https://skillicons.dev)

  
</div>
<br>

É preciso manter o padrão na comunicação dentro de uma comunidade e para isso utilizo [Webhooks do Discord](https://support.discord.com/hc/pt-br/articles/228383668-Usando-Webhooks). Ficar definindo toda vez as características e corpo de um Webhook pode demorar. Esse projeto envia modelos prontos de forma fácil e rápida para a comunidade.
